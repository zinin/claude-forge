## SESSION CONTEXT

Решения, принятые на брейншторме (в документах зафиксированы, здесь — обоснования и отвергнутые альтернативы):

- **`model: sonnet`** — осознанный выбор пользователя. haiku отвергнут (втрое дешевле по токенам, но выше риск нарушения протокола фоновых сборок и дублирования запусков при длинных логах — ровно та проблема, которую чиним); opus отвергнут как избыточный для парсинга логов. Не менять.
- **Агенту — только read-only диагностика** (`Bash(jps:*)`, `Bash(jstack:*)`, `Bash(ps:*)`), права `kill` у агента быть НЕ должно: философия агента — «report, don't fix»; убийство демонов делает главная сессия по секции «Daemon Recovery Procedure» скилла.
- **`--no-daemon` сознательно отвергнут** (проверено исследованием: lock contention не лечит, противоречит официальной рекомендации Gradle держать демон включённым). Не «улучшать» план его добавлением.
- **PreToolUse-хук для инъекции `timeout` отвергнут**: модификация поля `timeout` через `updatedInput` не документирована. Плагин также не может задавать env-переменные харнеса (`BASH_*_TIMEOUT_MS`) — поэтому хост-настройки идут рекомендательной секцией в README, а не кодом.

Состояние репозитория:

- Ветка **`build-runner-hardening` уже создана и активна**, спека и план уже закоммичены в неё. Новую ветку/worktree НЕ создавать.
